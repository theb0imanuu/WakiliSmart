# WakiliSmart: An ERP for Single-Practitioner Law Firms in Kenya


## 1. Project Overview

WakiliSmart is a comprehensive, monolithic Enterprise Resource Planning (ERP) system designed to meet the specific needs of a single-practitioner law firm in Kenya. The system is built to be a robust, all-in-one solution for managing clients, cases, appointments, and billing, with special consideration for the local legal and financial context.

The primary goal of this project is to provide a cost-effective, offline-first solution that addresses the gaps in existing legal practice management software. By leveraging a simple, monolithic architecture and a file-based database, WakiliSmart eliminates the need for expensive cloud hosting and ensures that the firm's data is always accessible.

## 2. Features

WakiliSmart is divided into three main portals, each tailored to a specific user role:

### 2.1. Public Portal

- **Book a Consultation:** A public-facing form that allows potential clients to book a consultation directly.

### 2.2. Secretary Dashboard

The Secretary Dashboard is the central hub for managing the firm's day-to-day operations.

- **Pending Appointments:** A table view of all pending appointments, with options to "Confirm" or "Reschedule".
- **New Case Form:** A form to create new cases for clients.

### 2.3. Advocate Portal

The Advocate Portal provides a high-level overview of the firm's financial health.

- **Financial Dashboard:**
  - **Total Revenue:** A widget displaying the total revenue generated by the firm.
  - **Outstanding Invoices:** A widget displaying the total amount of outstanding invoices.

## 3. System Design and Architecture

- **Monolithic Architecture:** The entire system is built as a single, cohesive unit, with the backend and frontend in the same repository.
- **Database:** WakiliSmart uses a **SQLite** file-based database with **Prisma ORM** for data access. This allows for offline-first capabilities and easy portability.
- **Authentication:** The system uses **JWT-based authentication** with Role-Based Access Control (RBAC) to ensure that users can only access the features relevant to their role.

## 4. Technologies Used

- **Backend:**
  - **Framework:** NestJS
  - **Database:** SQLite
  - **ORM:** Prisma
  - **Authentication:** JWT

- **Frontend:**
  - **Framework:** React
  - **Styling:** Tailwind CSS
  - **HTTP Client:** Axios
  - **Build Tool:** Vite

## 5. Setup and Installation

To run this project locally, you will need to have Node.js and npm installed.

### 5.1. Backend Setup

1.  Navigate to the `backend` directory:
    ```bash
    cd backend
    ```
2.  Install the dependencies:
    ```bash
    npm install
    ```
3.  Run the database migrations:
    ```bash
    npx prisma migrate dev
    ```
4.  Seed the database with the initial admin user:
    ```bash
    npx prisma db seed
    ```
5.  Start the backend server:
    ```bash
    npm run start:dev
    ```

### 5.2. Frontend Setup

1.  Navigate to the `frontend` directory:
    ```bash
    cd frontend
    ```
2.  Install the dependencies:
    ```bash
    npm install
    ```
3.  Start the frontend development server:
    ```bash
    npm run dev
    ```

The frontend will be available at `http://localhost:5173`.
